# Security

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/sushidev-team/renzu-ui/security/advisories/new). Include the affected package version, impact and a minimal reproduction using synthetic data. Do not post access tokens, kubeconfigs or private cluster data in issues or pull requests.

Security fixes target the latest released package version. Keep your dependencies up to date and review the release notes before upgrading.

This repository contains the public React UI kit and its Storybook. A public extension package does not grant Kubernetes permissions or access to the native application bridge.
